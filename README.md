# Первичный анализ датасета Abalone

## Описание

В данном проекте выполнен первичный анализ датасета Abalone.

Датасет содержит информацию о 4177 моллюсках и включает 9 признаков:

- gender — категория пола/возрастной группы;
- Length — длина;
- Diameter — диаметр;
- Height — высота;
- Whole weight — общий вес;
- Shucked weight — вес мяса;
- Viscera weight — вес внутренностей;
- Shell weight — вес раковины;
- Rings — количество колец.

## Проведённый анализ

В notebook выполнены:

- загрузка датасета;
- определение размера таблицы;
- определение типов данных;
- подсчёт пропущенных значений;
- получение базовых статистик;
- построение распределения признака Length;
- построение соотношения категорий gender;
- формулировка трёх наблюдений по данным.
